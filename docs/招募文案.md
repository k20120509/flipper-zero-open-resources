# 公开招募文案

【Flipper Zero 开源资源导航 · 公开征集资源】

Flipper Zero 开源资源导航（flipper-zero-open-resources）是一个面向所有人的开源资源仓库，把免费、开源、许可证清晰、可合法共享的固件、软件、工具、教程和硬件资料集中整理，让小白和小孩都能快速找到靠谱资源。

现在公开征集资源！任何人都可以参与，不需要会写代码：

- 你用过好用的固件、应用、工具、教程或硬件资料？欢迎分享。
- 提交方式：到 GitHub 仓库发起 Pull Request（拉取请求），把文件放到对应的分类目录（firmware/ 固件、software/ 软件与工具、hardware/ 硬件资料、tutorials/ 教程、other/ 其他资料），或通过 Issue 推荐链接。
- 所有内容必须经过管理员审查才会合并收录。审查标准：来源可追溯、许可证明确、链接有效、无恶意内容、遵守当地法规。
- 只收合法用途、开源 / 可共享的内容，不收费、不搞付费墙。

仓库地址：https://github.com/k20120509/flipper-zero-open-resources

贡献指南：docs/贡献指南.md
审核标准：docs/审核标准.md

欢迎来一起把资源库越建越全！
