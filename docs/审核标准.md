# 审核标准

本仓库只收录合法用途、开源 / 可共享、来源可追溯、许可证明确、链接有效的内容。管理员按下述标准逐项审核。

## 收录必要条件

- 来源可追溯：有明确的作者 / 项目 / 发布渠道，可验证出处。
- 许可证明确：明确标注 MIT、GPL、CC 等许可证，或明确授权可共享。
- 版本与固件匹配：资源标注的适用固件版本与仓库说明一致。
- 链接有效：提供真实可访问的链接。
- 无恶意载荷：不含恶意代码、木马、后门等有害内容。

## 明确不收录

- 违法教程（如非法侵入、破坏他人系统等）。
- 破解内容、无授权付费包。
- 违反当地无线电和网络安全法规的内容。
- 恶意、欺诈、钓鱼内容。

## 未成年人保护

- 未成年人使用和贡献需在监护人指导下进行。

## 下架机制

- 管理员有权下架不合规内容，并记录原因。
- 对被下架内容有异议的，可通过 Issue 提出申诉。

## 审核流程

1. 收到 Issue / PR。
2. 逐项核对来源、许可证、版本、链接和安全性。
3. 通过则合并 / 收录；不通过则说明原因。
