# 新手从这里开始

## Flipper Zero 是什么？

一句话：Flipper Zero 是一个长得像玩具、能研究各种无线信号和电子设备的开源多功能工具，常被称为"数字瑞士军刀"。

## 拿到设备先做什么？

按顺序做这三步：

1. 插 microSD 卡（FAT32 格式）到设备里。
2. 电脑上安装 qFlipper（官方桌面软件）。
3. 用 USB 连上设备，在 qFlipper 里把固件更新到 **Release 通道**。

详细步骤见 [docs/设置与上手.md](设置与上手.md)。

## 固件怎么选？

| 固件 | 一句话 |
| --- | --- |
| 官方固件（OFW） | 最稳定，功能最"干净" |
| Unleashed | 社区稳定基线，解锁了区域锁定的 Sub-GHz |
| Momentum | 界面最完善、可定制性最强 |
| RogueMaster | 应用最多，但稳定性最不可预测 |

新手建议：先用**官方固件**或 **Unleashed**，熟悉之后再折腾别的。

## 软件怎么装？

- qFlipper：管理设备里的文件、更新固件。
- Flipper Lab：浏览器里打开就能直接装应用，不用安装软件。
