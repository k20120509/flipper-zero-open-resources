# はじめに（初心者ガイド）

## Flipper Zero とは？

一言で：Flipper Zero は、無線信号や電子機器を調査できるオープンソースの多機能ツールで、「デジタル・スイスアーミーナイフ」とも呼ばれています。

## デバイスを入手したら最初にやること

この順番で3つのことを行います：

1. microSD カード（FAT32 でフォーマット）をデバイスに挿入します。
2. パソコンに qFlipper（公式デスクトップアプリ）をインストールします。
3. USB でデバイスを接続し、qFlipper でファームウェアを **Release チャンネル** に更新します。

詳しい手順は [docs/设置与上手.md](设置与上手.md)（中国語）を参照してください。

## ファームウェアの選び方

| ファームウェア | 一言で |
| --- | --- |
| 公式（OFW） | 最も安定、機能は最小限 |
| Unleashed | コミュニティの安定版ベースライン、地域ロックの Sub-GHz を解除 |
| Momentum | UI が最も充実、カスタマイズ性が最も高い |
| RogueMaster | アプリ数は最多だが、安定性は最も予測不能 |

初心者には **公式** か **Unleashed** をおすすめします。慣れてから他のものに挑戦しましょう。

## アプリのインストール方法

- qFlipper：デバイスのファイル管理とファームウェア更新。
- Flipper Lab：ブラウザ上でアプリを直接インストールできます。
