# Start Here (Newcomer's Guide)

## What is Flipper Zero?

In one sentence: Flipper Zero is an open-source multi-tool shaped like a toy, used to research wireless signals and electronics — often called a "digital Swiss Army knife."

## First steps after getting your device

Do these three things in order:

1. Insert a microSD card (formatted as FAT32) into the device.
2. Install qFlipper (the official desktop app) on your computer.
3. Connect the device via USB and, in qFlipper, update the firmware to the **Release channel**.

Detailed steps: [docs/设置与上手.md](设置与上手.md) (Chinese)

## How to choose firmware?

| Firmware | In one sentence |
| --- | --- |
| Official (OFW) | Most stable, cleanest feature set |
| Unleashed | Community stable baseline; unlocks region-locked Sub-GHz |
| Momentum | Best UI, most customizable |
| RogueMaster | Most apps, but the least predictable stability |

For beginners: start with **Official** or **Unleashed**, then experiment later.

## How to install apps?

- qFlipper: manage device files and update firmware.
- Flipper Lab: install apps right in your browser — no local app required.
