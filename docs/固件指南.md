# 固件指南

本页介绍 Flipper Zero 主流固件的全景和选择逻辑。以下固件均为开源免费项目，具体许可证以各仓库为准。

## 固件全景

### 官方固件（OFW）

- 仓库：flipperdevices/flipperzero-firmware
- 特点：稳定性最高，额外功能最少，与硬件和官方文档匹配度最好。
- 注意：部分地区的滚动码（Rolling Code）协议只收不发（受区域限制）。
- 适合：新手、追求稳定、喜欢官方原味体验的用户。

### Unleashed

- 仓库：DarkFlippers/unleashed-firmware
- 特点：基于官方固件的社区稳定分支，解锁区域锁定的 Sub-GHz 频段，支持更多外部模块，插件更丰富。
- 适合：想要更多功能、又希望保持相对稳定的用户。

### Momentum

- 仓库：Next-Flip/Momentum-Firmware
- 特点：基于官方固件，整合了 Unleashed 的大量功能；界面可定制性最强；自带资产管理、增强的 JavaScript 运行时、约 183 个预装外部应用（截至 2025.04）。
- 适合：追求界面和功能完整体验的用户。

### RogueMaster

- 仓库：RogueMaster/flipperzero-firmware-wPlugins
- 特点：基于 Unleashed，应用和插件数量最多（约 421 个预装），功能激进。
- 注意：稳定性最不可预测，更新频繁，可能出现未知问题。
- 适合：喜欢折腾、能接受不稳定性的高级用户。

### Momentum-Firmware-CN（中文社区补充）

- 特点：基于 Momentum 的中文分支，提供中文固件编译、内置中文字库和中文应用菜单。
- 交流：QQ 交流群 716547787。
- 适合：中文用户、希望界面汉化的用户。

## 选择逻辑

```
追求稳定、刚入门        → 官方固件（Release 通道）
想要更多功能、较稳定    → Unleashed
想要界面完善、可定制    → Momentum
喜欢折腾、不惧不稳定    → RogueMaster
想要中文界面           → Momentum-Firmware-CN
```

## 新手建议

先刷 Release 通道的官方固件，熟悉设备基本操作和生态；熟悉之后再根据需求考虑 Unleashed 或 Momentum。

## 刷机注意事项

- 刷机前备份 microSD 卡中的重要数据。
- 使用官方 qFlipper 或各固件官方渠道提供的方式刷机。
- 刷第三方固件前，请自行确认固件的许可证和来源可追溯。
- 遵守当地无线电与网络安全法律法规。
