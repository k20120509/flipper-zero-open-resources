# 设置与上手（从零到可用）

## 步骤

### 1. 准备 microSD 卡

- 使用 FAT32 格式的 microSD 卡。
- 插入设备。

### 2. 安装 qFlipper

- 支持 Windows 10/11、macOS、Linux。
- 下载地址：https://flipperzero.one/update

### 3. 更新固件

- 用 USB 线连接设备与电脑。
- 打开 qFlipper，等待识别设备。
- 进入 Advanced controls（高级控制）→ Update Channel（更新通道）→ 选择 RELEASE。
- 点击 Update（更新）。

### 4. 等待重启

- 更新完成后设备会自动重启。
- 重启后即可正常使用。

### 5. 安装外部应用

两种方式任选：

- qFlipper：File manager（文件管理器）中把 .fap 文件拖放到 apps 目录。
- Flipper Lab：浏览器打开 https://lab.flipper.net，通过 Web Serial 连接后安装。

### 6. 开启 5V GPIO 供电（按需）

- Main Menu → GPIO → 5V on GPIO → ON。

## 常见问题

- qFlipper 无法识别设备：换 USB 线 / 换接口，或检查驱动。
- 更新失败：先备份数据，再用 qFlipper 恢复官方固件。
