# 硬件与模块

## GPIO

- 共 18 个引脚，3.3V I/O，耐压能力有限。
- 3.3V I/O 引脚：5V 仅在输入模式下耐受。
- +3.3V 引脚：默认开启，最大输出 1.2A。
- +5V 引脚：需在 GPIO 应用中手动开启。
- 开启方式：Main Menu → GPIO → 5V on GPIO → ON。

## Wi-Fi Developer Board

- 芯片：ESP32-S2-WROVER。
- 能力：Wi-Fi、USB-C、GPIO 扩展。
- 用途：调试、固件烧录、无线协议研究等。

## 硬件使用安全

- I/O 总功耗不要超过 5W。
- 单个引脚输出电流不要超过 20mA。
- 不要把 5V 输出的外设直接接到 3.3V I/O 引脚。
- 接线前断电，反复确认引脚定义，避免短路损坏设备。
