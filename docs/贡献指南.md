# 贡献指南

感谢你愿意为社区贡献资源。所有人（包括小白）都可以参与，不需要会写代码。

## 三条贡献路径

### 路径一：Issue 推荐资源

- 打开仓库 Issues 页面，选择"推荐资源"模板。
- 必须注明：资源名称、来源链接、作者、许可证、版本、适用固件、更新时间。
- 管理员审核通过后会加入 index/resources.md 和 index/resources.csv。

### 路径二：Issue 报失效

- 使用"失效报告"模板，说明哪个资源失效、失效表现（404 / 下载失败 / 页面关闭等）。
- 如果能提供新的有效链接，一并附上。

### 路径三：PR 提交资源或代码

- 推荐先开 Issue 讨论，再提 PR。
- 提交时更新 index/resources.csv 和 index/resources.md。
- 遵循仓库 PR 模板的检查项。

## 贡献必填信息

每次推荐资源，至少提供：

- 资源名称
- 来源链接
- 作者 / 来源
- 许可证
- 版本 / 适用固件
- 更新时间

## 注意事项

- 只推荐合法用途、开源 / 可共享、来源可追溯、许可证明确、链接有效的内容。
- 未成年人请在监护人指导下贡献。
- 提交 PR 即表示你同意以仓库许可证共享该贡献。
