# 软件与工具

## qFlipper

- 官方桌面应用（支持 Windows / macOS / Linux）。
- 用途：更新固件、管理 microSD 卡上的文件、修复损坏的固件。
- 地址：https://flipperzero.one/update

## Flipper Lab

- 浏览器端工具，通过 Web Serial 连接设备。
- 在 Chrome / Edge 中即可安装应用和固件，无需安装本地软件。
- 地址：https://lab.flipper.net

## uFBT（Flipper Build Tool）

- 跨平台应用开发工具。
- 用途：编译、调试、部署 FAP 应用；自动生成 VSCode 配置。
- 适合：想自己开发 Flipper 应用的开发者。

## JavaScript SDK

- 官方 @flipperdevices/fz-sdk 以及 Momentum 的 JS SDK。
- 用途：用 JavaScript / TypeScript 编写应用，无需学习 C 语言。
- 适合：Web 开发者快速上手 Flipper 应用开发。

## FAP（Flipper Application Package）

- Flipper 应用的可执行包格式，包含代码、资源和元数据。
- 在固件菜单中即可加载运行。

## 外部应用来源

- 官方应用目录（Flipper Lab / Mobile App）
- Awesome Flipper 资源清单
- 各固件自带的预装应用包
