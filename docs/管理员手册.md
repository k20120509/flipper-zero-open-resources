# 管理员手册

## 职责边界

- 管理员只做：索引、标注、审核、下架违规内容。
- 管理员不擅自修改作者的代码和资源内容。
- 保留原作者的署名和许可证信息，不得移除或替换。

## 日常维护

- 定期清理过期和失效资源（链接失效、项目停更、许可证变更等）。
- 对失效资源标注状态或移出索引。
- 保持 index/resources.csv 与 index/resources.md 数据一致。

## 审核流程

逐项核对：

1. 来源：能否追溯原作者 / 项目 / 发布渠道。
2. 许可证：是否明确、是否允许共享。
3. 版本：是否标注适用固件版本，与说明是否一致。
4. 链接：是否真实有效。
5. 安全性：是否含恶意载荷、恶意代码。

## 下架规则

- 违反审核标准的内容，管理员有权下架。
- 下架时记录原因；有异议的可通过 Issue 申诉。
- 涉及法律风险的，及时提醒并移除。

## 沟通

- 对新贡献者保持友好、耐心的沟通。
- 审核不通过时说明具体原因，给出改进建议。
